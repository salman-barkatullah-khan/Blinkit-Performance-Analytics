📊 Blinkit Performance Analytics Dashboard

A Power BI dashboard designed to analyze Blinkit's operational performance, customer behavior, sales trends, and delivery metrics. This project provides a data-driven understanding of business performance to support informed decision-making.

🚀 Project Overview

The Blinkit Performance Analytics Dashboard aims to provide a comprehensive view of:

Sales performance

Order demand patterns

Delivery efficiency

Customer satisfaction

Category-wise insights

Location-based performance

The goal is to identify improvement opportunities and support strategic planning for fast-delivery operations like Blinkit.

🛠️ Tools & Technologies Used
Tool / Technology	Purpose
Power BI	Dashboard development & visualization
Power Query	Data cleaning & transformation
DAX	Calculated measures & KPIs
Excel / CSV	Source dataset
📁 Dashboard Features
1️⃣ Sales Insights

Total Sales

Average Order Value

Daily / Monthly Trends

Category-wise Contribution

2️⃣ Customer Insights

Feedback Analysis

3️⃣ Delivery Performance

On-time Delivery Rate

Average Delivery Time

4️⃣ Operational KPIs

Total Orders

Fulfillment Efficiency
